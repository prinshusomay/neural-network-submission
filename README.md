# The Neural Network: Year Programme 2026-27 (applicant submission)

A plain HTML, CSS and JavaScript website for my Round 2 recruitment submission. Applicant, not a member of the club. Not an official club site.

All files sit in one folder (no sub-folders): `index.html`, `curation.html`, `outreach.html`, `about.html` and their pages (`cur-*`, `out-*`, `about-*`), `style.css`, `main.js`, and the content files `site.json`, `sessions.json`, `partners.json`, `templates.json`, `sources.json`.

Edit the JSON files to change content. A missing field is shown as "Not yet loaded from my workbook". Nothing is invented. Do not send the email templates until my role is confirmed and a faculty advisor agrees.

To view locally, run `python3 -m http.server` in this folder and open http://localhost:8000/.
